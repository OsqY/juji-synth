## MODIFIED Requirements

### Requirement: Black key visibility
Black keys SHALL have a visible gap between them and adjacent white keys. The gap SHALL be created by reducing black key width and adding a distinct border.

#### Scenario: Black key has gap
- **WHEN** looking at the keyboard
- **THEN** there is a visible gap between each black key and the adjacent white keys

#### Scenario: Black key border visible
- **WHEN** looking at a black key
- **THEN** the right edge has a lighter border that distinguishes it from the white key
