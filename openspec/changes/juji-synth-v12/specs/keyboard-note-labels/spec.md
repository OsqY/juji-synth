## MODIFIED Requirements

### Requirement: Black key visibility
Black keys SHALL be distinguishable from the keyboard background by using a lighter shade than the current near-invisible dark purple.

#### Scenario: Black key visible
- **WHEN** the keyboard is displayed
- **THEN** black keys are visually distinct from the keyboard background

### Requirement: Note label readability
Note labels on both white and black keys SHALL use colors with sufficient contrast against their background.

#### Scenario: White key label readable
- **WHEN** looking at a white key
- **THEN** the note label text is dark enough to read against the light key surface

#### Scenario: Black key label readable
- **WHEN** looking at a black key
- **THEN** the note label text is light enough to read against the dark key surface
