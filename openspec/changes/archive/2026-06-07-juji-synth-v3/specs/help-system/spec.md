## MODIFIED Requirements

### Requirement: Tooltip system
The synthesizer SHALL provide contextual tooltips on all interactive controls. Tooltips SHALL work with the new large knob components and tabbed layout without interference.

#### Scenario: Tooltip appears on long-press
- **WHEN** user long-presses (500ms) on any knob or control
- **THEN** a tooltip appears showing control name, current value, and parameter description
