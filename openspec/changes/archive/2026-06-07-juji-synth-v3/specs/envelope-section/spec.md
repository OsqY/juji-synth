## MODIFIED Requirements

### Requirement: Dual envelope generators
The synthesizer SHALL provide two ADSR envelope generators displayed as a full-width tab panel with large 3D knobs for each stage and a real-time ADSR curve visualization.

#### Scenario: Envelope triggers on note-on
- **WHEN** a note is pressed
- **THEN** the envelope generator begins the attack phase

#### Scenario: Envelope panel full-width
- **WHEN** the ENV tab is selected
- **THEN** the envelope panel fills the available width with large ADSR knobs for both amp and filter envelopes, and a real-time curve visualization
